# Recoil

An experimental React-like UI framework for iOS and Android, built on top of Yoga for layout.

## Projects

- `Recoil/` — Core framework (iOS)
- `RecoilApp/` — iOS demo app
- `RecoilAndroidApp/` — Android demo app

## Getting Started

```sh
bundle install
bundle exec pod install
open RecoilApp/RecoilApp.xcworkspace
```
